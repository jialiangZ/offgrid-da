# METAR 五变量观测接入

本模块为新实验提供观测数据接口，不修改已冻结的 T2M-only 实验代码、缓存或权重。

## 已接入变量

| ID | 物理量 | 单位 | 原始字段 / 转换 |
|---|---|---|---|
| 0 | 近地面温度 | K | temperature |
| 1 | U 风分量 | m/s | −windSpeed × sin(windDir) |
| 2 | V 风分量 | m/s | −windSpeed × cos(windDir) |
| 3 | 近地面露点 | K | dewpoint |
| 4 | 海平面气压 | Pa | seaLevelPress |

高度表气压 altimeter 不作为海平面气压代用。没有增加 RH 或地面比湿，避免将同一湿度信息作为多个独立观测重复使用。露点不是 1000 hPa 比湿，也不对应现有 82 个输出通道中的某一个。

## 时间、缺测和质量处理

- 有效时刻 t 的观测窗为 (t−60 min, t]；接收截止 t+30 min。
- 使用原始小时分区，读取覆盖窗口所需的三个分区，按 timeObs 再筛选。
- 每个站点、每种变量独立保留最新有效报告；时间相同时优先最早接收。缺测不删除该站的其他有效变量。
- U/V 来自同一报告并共同通过风速、风向检查，采用气象学来向约定。静风可在风向缺测时生成零分量；非静风的可变/缺失方向不生成 U/V。
- 露点在有效温度存在时不得超过温度 1 K，容许原始编码取整差异。
- 使用既有 DD 描述符规则、有限值及物理范围检查；这些描述符不等同完整 MADIS 数值 QC 标志。
- 不按 ERA5 创新拒绝观测，不生成伪造的湿度或压力值。
- 所有变量共用 seed=42、default 的站点角色划分；同一站的所有观测类型在同一侧。每个标量是一个 token，station_ids 按 token 对齐，允许同站重复。

## 归一化和误差

读取既有 outputs/single_da_05_input82_ablation/normalization.json，统计仅来自 2018–2020 年背景。温度、U、V、MSLP 使用对应通道的均值和标准差；露点明确使用 T2M 的温度坐标尺度。露点没有另拟合均值，也没有使用验证期统计。

每个 token 携带物理值、归一化值、变量 ID、位置和高程、时间偏移、来源、质量编码、仪器及代表性误差假设、归一化误差。当前观测编码器消费值、类型、位置、时间、来源和质量；误差字段是元数据，尚未形成独立的误差加权损失或似然。

初始误差假设（仪器 / 代表性标准差）：T 与 Td 为 1 / 2.5 K，U/V 为 1.5 / 3 m/s，MSLP 为 100 / 150 Pa；用平方和开方得到总误差。这些不是经校准的误差估计，更不意味着某种最优赋权。

## 使用与范围

新入口：`offgrid_da.data.multivar_dataset.MultivarMetarDataset(root, split)`；批处理：`multivar_collate`。背景输入为 [B,82,121,240]；不规则标量观测为 [B,N]，位置为 [B,N,3]，padding 有显式掩码。

该适配器当前复用旧版 T2M 网格参考目标，目的是接通多变量观测。**82 通道分析输出、完整状态目标和多变量损失仍需另外实现，当前没有启动 82 通道更新训练。** 创新输入保持禁用。

准备和审计：`.venv/bin/python -u scripts/prepare_multivar_metar.py --workers 4`。完整范围仅为 train 4384 + val 1460，不读取 2022。中断后可复用逐时刻缓存。缓存绑定转换代码、策略、归一化和原始分区 SHA256，验证字段变化时拒绝沿用。

GPU 工程验收：`CUDA_VISIBLE_DEVICES=0 .venv/bin/python scripts/verify_multivar_metar.py`。使用两个训练、两个验证时刻，检查站点隔离、逐变量归一化、批处理、有限前向/反向、无观测恒等和五种观测类型敏感性。验收借用现有仅输出 T2M 的模型，不是预报性能实验。

验收中局地邻居上限为 80 个标量 token。扩展成五种观测后，同一站点会产生多个 token；沿用 16-token 限额会减少实际可见站点数。正式对照前应明确按站点还是按 token 限邻居，并控制比较口径；不能将工程验收中的 80 直接当作已验证最优参数。

## 已执行验证

- 14 项新旧相关测试通过。
- 真实训练/验证共四个时刻均有五类有效观测，站点角色隔离、归一化和时间窗检查通过。
- GPU0 上两样本批次 [2,82,121,240]，观测 padding [2,16111]，三步前后向有限；五类观测均有非零输入敏感性，无观测严格回到背景。
